## REPLIT PROMPT — CCTV PHOTO & VIDEO ANALYSIS

Add a complete **CCTV Photo and Video Analysis module** to my existing project.

Do not modify or remove the existing features. Integrate this feature into the current project.

### 1. CCTV PHOTO UPLOAD

Create a page called:

**CCTV Photo Analysis**

Allow the user to upload CCTV photographs in:

* JPG
* JPEG
* PNG
* WEBP

After uploading:

1. Display the uploaded image.
2. Detect all faces in the image.
3. Draw bounding boxes around detected faces.
4. Extract facial features/embeddings.
5. Compare detected faces with the existing missing-person database.
6. Display the best possible matches.
7. Show a similarity/confidence score.
8. Show the detected face and the matched person's registered photograph side-by-side.

Example result:

**Detected Person #1**

Possible Match: [Missing Person Name]

Similarity Score: 91%

Status: Possible Match — Human Verification Required

If no face is detected, display:

**"No face detected. Please upload a clearer CCTV image."**

If multiple faces are detected, analyze each face separately.

---

### 2. CCTV VIDEO UPLOAD

Create a page called:

**CCTV Video Analysis**

Allow users to upload CCTV footage.

Support common formats:

* MP4
* AVI
* MOV
* MKV
* WEBM

After uploading the video:

1. Display video information.
2. Show video preview.
3. Extract video duration, FPS and resolution.
4. Process the video on the server.
5. Extract frames at regular intervals.
6. Detect faces from the extracted frames.
7. Track repeated faces across frames.
8. Generate facial embeddings.
9. Compare faces with the existing missing-person database.
10. Find possible matches.
11. Record the exact timestamp where the possible match appears.
12. Display the results.

---

### 3. VIDEO FRAME PROCESSING

Do not process every single frame unnecessarily.

Use configurable frame extraction.

Default:

**1 frame per second**

Allow the user/admin to select:

* 0.5 seconds
* 1 second
* 2 seconds
* 5 seconds

For each processed frame:

**Video → Frame → Face Detection → Face Embedding → Database Comparison**

### 4. FACE TRACKING

00:01:15

* Track ID
